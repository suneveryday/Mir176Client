客户端环境检查仅在 Windows CheckRemoteDebuggerPresent 成功且明确报告调试器已附加时停止启动，并显示具体的调试器提示。接口缺失或调用失败保留为不可用状态，不判定外挂。系统托盘窗口结构、托盘文字以及系统 DLL 的函数入口字节不作为外挂证据；不再访问 Explorer 进程内存。Release 构建仍启用检查定时器，定时器在显示阻止提示前关闭，避免重复提示。
